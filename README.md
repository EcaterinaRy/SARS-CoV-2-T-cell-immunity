# SARS-CoV-2-T-cell-immunity
Main directory contains all the scripts (Final_0... - Final_6...) that are needed to draw Fig. 1-6 from the main text.

Tables.7z file contains the input data that is needed to draw Fig. 1-6 from the main text (except UShER data that should be installed on cluster): 
 - HLAs.csv - HLAs frequencies (by population),
 - world_hla_alleles.csv - world HLA frequencies (see References),
 - tcell_table_export_*.csv - immunogenic epitopes,
 - omicron_sequences.csv, delta_sequences.csv, aa_seq_wuhan.csv - aa sequences of Omicron, Delta and Wuhan,
 - EVsAndMutsFrequenies_FromUsher.tar - data from Usher (freauences from SNPs, EVs, number of samples per country),
 - city, country, state folders - data per country (wt and mut EVs with HLA affinity and frequencies of EVs and HLA).
